# NMS Cyrillic Input Fix

Мод исправляет ввод кириллицы в штатных текстовых полях **No Man’s Sky** под Windows x64, включая поиск Picker Tweaks (NMS.rs).

**Версия мода:** 1.0.0  
**Проверенная сборка игры:** 185034

## Возможности

- Ввод русских букв, включая смешанный текст с латиницей.
- Переименование баз и других игровых объектов.
- Поиск предметов на русском через Picker Tweaks.
- Использование штатной функции вставки UTF-8 и исправление фильтрации байтов.
- Проверка сигнатур перед установкой перехватов; `NMS.exe` на диске не изменяется.

**Ограничения:** обработчик клавиатуры поддерживает кириллический диапазон U+0400–U+047F. Другие многобайтовые символы не добавлены. Лимиты строк остаются оригинальными: русские буквы занимают два байта UTF-8, поэтому поле на 42 байта вмещает не более 21 русской буквы. Совместимость с другими сборками игры не подтверждена.

## Установка

1. Закройте игру.
2. Удалите предыдущую диагностическую версию `Binaries/plugins/NMS_UnicodeProbe.asi`, если она установлена.
3. Убедитесь, что установлен загрузчик [Ultimate ASI Loader x64](https://github.com/ThirteenAG/Ultimate-ASI-Loader/releases) (например, `winmm.dll`). Не заменяйте без необходимости существующие загрузчики.
4. Поместите `Binaries/plugins/NMS_CyrillicInputFix.asi` в каталог игры с сохранением структуры папок.
5. Запустите игру. В файле `NMS_CyrillicInputFix.log` ожидается строка `Fix active`.

Удаление: закройте игру и удалите `Binaries/plugins/NMS_CyrillicInputFix.asi`.

## Совместимость и проверка

Исправление функционально проверено пользователем на диагностической сборке **0.4**: ввод и удаление русских букв, смешанный текст, переименование базы, сохранение и загрузка после полного перезапуска, поиск Picker Tweaks без учёта регистра.

**Версия 1.0.0** сохраняет исправления версии 0.4, но убирает журналирование вводимого текста. Бинарник 1.0.0 собран и проверен статически; отдельный запуск релизного бинарника в игре на момент публикации не подтверждён. Мультиплеер и другие версии игры не проверялись.

## Сборка

Исходники находятся в каталоге `source/`. Для сборки под Windows x64 требуются LLVM/Clang и LLD в `PATH`; выполните `source/build.cmd`. Сценарий не требует Windows SDK.

## Безопасность

Мод меняет машинный код **в памяти процесса**, предварительно сверяя сигнатуры. При несовпадении сигнатур исправление не включается. После обновлений No Man’s Sky необходима повторная проверка совместимости. Программа поставляется как экспериментальное исправление, используйте её на свой риск.
