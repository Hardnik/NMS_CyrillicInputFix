# NMS Cyrillic Input Fix

**Версия 1.0.0 · No Man’s Sky · Windows x64**

Модификация исправляет ввод кириллицы в штатных текстовых полях No Man’s Sky: при использовании русской раскладки игра игнорирует вводимые буквы.

Исправление также работает в поиске Picker Tweaks из набора модификаций NMS.rs. Для обычного ввода текста установка NMS.rs не требуется.

## Возможности

- Ввод русских букв, включая «ё» и «Ё».
- Смешанный ввод кириллицы и латиницы.
- Корректное удаление символов.
- Переименование объектов и сохранение введённых названий.
- Поиск по русским названиям в Picker Tweaks без учёта регистра.

Модификация использует штатную функцию вставки UTF-8, исправляя обработку многобайтовых символов при вводе с клавиатуры. Поддерживается диапазон Unicode U+0400–U+047F.

Оригинальные ограничения длины текстовых полей сохраняются. Кириллические символы занимают два байта в UTF-8: например, поле с ограничением в 42 байта вмещает до 21 русской буквы.

## Установка

1. Закройте игру.
2. Если ASI-загрузчик ещё не установлен, установите [Ultimate ASI Loader x64](https://github.com/ThirteenAG/Ultimate-ASI-Loader/releases), например в виде `winmm.dll`. Не заменяйте существующие загрузчики без необходимости.
3. Распакуйте каталог `Binaries` из архива модификации в корневой каталог игры. Файл должен находиться по пути `Binaries/plugins/NMS_CyrillicInputFix.asi`.
4. Запустите игру.

## Совместимость

- Проверенная сборка No Man’s Sky: **185034**.
- Совместимость с NMS.rs и Picker Tweaks подтверждена.
- Перед применением исправления проверяются три сигнатуры машинного кода. При несовпадении сигнатур исправление не применяется.
- Файл `NMS.exe` на диске не изменяется.
- После обновления игры совместимость необходимо проверить заново.

Релиз 1.0.0 проверен непосредственно в игре: ввод кириллицы, удаление символов, переименование базы, поиск в Picker Tweaks, сохранение и восстановление названий после полного перезапуска игры работают корректно.

Работа в мультиплеере и на других сборках игры отдельно не проверялась.

## Удаление

Закройте игру и удалите файл `Binaries/plugins/NMS_CyrillicInputFix.asi`. Восстанавливать оригинальный исполняемый файл игры не требуется.

## Сборка из исходников

Исходный код находится в каталоге `source`.

Для сборки необходимы LLVM/Clang и LLD, доступные через `PATH`. Установка Windows SDK не требуется.

Запустите `source/build.cmd`. Готовый файл будет создан в `Binaries/plugins/NMS_CyrillicInputFix.asi`.
